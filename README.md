# AI Music Generator

## Overview

AI Music Generator is a web-based application that automatically generates simple musical melodies using Artificial Intelligence concepts. The system creates random note sequences and exports them as MIDI files, allowing users to generate unique music with a single click.

This project demonstrates the application of AI techniques in music composition and generation.

---

## Features

* Generate AI-based music melodies
* Export generated music as MIDI files
* Simple and user-friendly interface
* Web application built using Flask
* Fast and lightweight implementation

## How It Works

1. User opens the web application.
2. Clicks the Generate Music button.
3. The AI system generates a sequence of musical notes.
4. Notes are converted into a MIDI file.
5. Generated music is saved in the generated_music folder.
